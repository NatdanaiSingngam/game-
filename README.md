# 🍺 Monster Drink Battle ⚔️

เกมปาร์ตี้ลงดันเจี้ยนสไตล์ chibi สำหรับวงเพื่อน 2–10 คน เล่นบนเครื่องเดียวผลัดกันกด (มือถือ/แท็บเล็ต/คอม)

**▶ เล่นเลย:** https://natdanaisingngam.github.io/game-/

## โหมดเล่น
- **📱 เครื่องเดียว** — ผลัดกันกดบนเครื่องเดียว 2–10 คน
- **🌐 ออนไลน์** — คนหนึ่งกด *สร้างห้อง* แล้วแชร์ลิงก์/รหัส 5 ตัว เพื่อนเข้าห้องด้วยมือถือตัวเอง เลือกตัวละครของตัวเอง (1 เครื่องเพิ่มได้หลายตัว รวมไม่เกิน 10) ถึงตาใคร มือถือคนนั้นสั่นให้เลือกท่า ใครตาย/มานาหมด คนนั้นกดยืนยันว่ายกแล้ว · รีโหลด/หลุดแล้วเข้าห้องเดิมให้อัตโนมัติ
  - ระบบออนไลน์ใช้ Supabase Realtime (หัวห้องเป็นคนรันเกม เครื่องเพื่อนส่งคำสั่ง)

## กติกาดื่ม
- 💀 **HP หมด (ตาย)** → ยก **1 แก้ว** แล้วฟื้นคืนชีพ HP/SP เต็ม
- 💧 **มานาหมด** (SP ไม่พอใช้สกิลที่ถูกที่สุด) → ยก **¼ แก้ว** ได้ **+10 SP**
- ห้องปริศนาบางห้องมีอีเวนต์ดื่มพิเศษ 🍻

## ระบบเกม
- **6 อาชีพ:** นักดาบ · เมจ · อาร์เชอร์ · อะโคไลท์ · ทีฟ · เมอร์ชานท์ (สกิลปลดล็อกที่ Lv1 / Lv5 / Lv10)
- **ดันเจี้ยน:** แต่ละชั้นสุ่ม 3–6 ห้อง เลือกห้องเองได้ (มอน, อีลีท, หีบสมบัติ/มิมิค, ห้องปริศนา, กองไฟ) เคลียร์ 2 ห้องแล้วบุกห้องบันไดลงชั้นถัดไป
- **บอส MVP 👑 ทุก 5 ชั้น** ยิ่งลึกมอนยิ่งโหด
- **เทิร์นตาม SPD** (AGI สูง = ได้เล่นบ่อย) ดูลำดับได้จากแถบบนสนาม
- **เลเวล + อัพสเตตัส** STR / AGI / VIT / INT / DEX / LUK
- บันทึกเกมอัตโนมัติในเบราว์เซอร์ · เพิ่มลงหน้าจอโฮมมือถือได้ (Add to Home Screen)
